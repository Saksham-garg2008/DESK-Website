01

ACTION LAYER

From requests to actions

DESK can interpret supported requests and pass structured actions to application code for execution. This creates a defined path between what the user asks and what the application is permitted to do.

Actions are limited to implemented capabilities. DESK is not intended to turn every instruction into an arbitrary shell command or grant an AI unrestricted control over the computer.

02

DESKTOP INTEGRATION

Work with your desktop

DESK supports opening desktop applications and web destinations through implemented actions. This includes supported browser destinations and services, depending on your system and installed applications.

Browser profile selection can be configured through DESK settings, keeping that choice under the user's control rather than leaving it to the AI to decide.

Actual behaviour depends on the operating system, application availability, configuration, and the action being requested.

03

FILESYSTEM

Find files. Create project structures.

DESK can discover supported filesystem locations and search for files and directories by name. Searches can use exact or partial names, helping you locate items without manually browsing every folder.

Filesystem discovery is designed to work with user-accessible locations, including relevant mounted storage where supported. Search results may be incomplete if a location cannot be accessed.

Supported actions can create directories, including missing parent directories, and create new text files with supplied content. File creation does not overwrite an existing file at the target path.

Search and creation are distinct operations. Filename search does not read file contents or modify the files it finds; creation is limited to supported actions rather than unrestricted filesystem access.

04

ARTIFACTS & USER DATA

Keep useful outputs organised

DESK includes an artifact-handling layer for working with generated outputs. Artifact management is separate from the core inference and action responsibilities, making it easier to organise the different parts of the application.

The exact formats and behaviours available depend on the current release. Consult the source code and documentation for implementation details.

◇
05

ARCHITECTURE

Built in separate layers

DESK separates responsibilities such as inference, action execution, filesystem operations, memory, history, configuration, and artifact handling into dedicated modules.

This modular structure helps contributors inspect individual components and improve them without turning the entire application into one large script.

DESK is built with Python and PySide6, with an emphasis on a desktop application that can run without requiring a heavyweight local language model.

06

PROJECT ECOSYSTEM

DESK Android Companion

DESK's wider project includes an Android Companion codebase. The desktop application provides a QR-code generator to support the connection workflow.

Open the pairing interface in DESK using Ctrl + Shift + P. Follow the instructions shown in the application to continue the connection process.

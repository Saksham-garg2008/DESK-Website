01 / THE IDEA

Less spectacle.
More utility.

DESK is an open-source desktop AI assistant built to make the bridge between asking and doing more useful.

Instead of treating every request as plain text, DESK uses a modular application architecture to interpret supported actions and hand them to application-side logic for validation and execution. The goal is a tool you can inspect, understand, and help improve.

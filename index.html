A milestone of consolidation. A stronger foundation for what comes next.

Alpha Edition brings together the essential DESK experience: agent interactions, supported filesystem operations, artifact workflows, persistent user data, and Android Companion integration. The focus is not simply adding more features, but making the existing experience more cohesive and dependable.

02 / WHAT'S NEW

One release.
A stronger foundation.

01

DESKTOP INTERACTION

More useful agent workflows

Expanded supported desktop actions, improved application launching and browser workflows, and configurable browser profile selection through DESK settings.

↗
02

FILESYSTEM

From search to project structure

Improved filesystem discovery and name-based search across accessible locations, alongside supported folder and new text-file creation actions.

⌕
03

COMPANION

Desktop meets Android

The desktop app includes a QR-code-based pairing workflow for DESK Companion, accessible with Ctrl + Shift + P. The Companion API also supports artifact listing.
